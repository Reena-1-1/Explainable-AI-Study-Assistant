Report Outline

1. Abstract

This project presents an Explainable AI Study Assistant that answers questions using information retrieved from uploaded PDF documents. It aims to make answers easier to verify by providing relevant passages and page references.

2. Introduction

Explainable AI helps users understand and verify AI-generated outputs. This project combines document-based question answering with evidence from the uploaded PDF.

3. Problem Statement

AI-generated answers may be difficult to verify and may not clearly show their supporting sources. The project addresses this issue by retrieving relevant document passages and displaying page references.

4. Objectives

- Allow users to upload PDF documents.
- Answer questions using information from the uploaded document.
- Display supporting passages and page references.
- Indicate when the answer is not found in the document.
