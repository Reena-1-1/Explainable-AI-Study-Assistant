# Team rules
1. Never push to `main`. Work on your own branch and open a Pull Request.
2. Edit only your own files (see table in team_instructions/).
3. Commit small and often (at least 5 commits each).
4. Never commit API keys. Use `.env`.
5. New library? Add it to requirements.txt.
6. Before new work: `git checkout main` then `git pull origin main`.
